# ECU Workbench (ECUwb)

> **This repository contains no source code.**
> It is used as the public home for issue tracking.

---

**ECU Workbench (ECUwb)** is an integrated ECU flashing, tuning, and diagnostics studio for motorcycle and powersports ECUs — built by [MCU Innovations, Inc.](https://mcuinnovations.com)

### Features

- **Flash with confidence** — Read/backup, write, and verify with a workflow designed to reduce mistakes
- **Tune with evolving definitions** — ECU definitions are updated regularly to expand editable parameters over time
- **Diagnostics** — Clear DTCs and validate changes quickly (capabilities vary by ECU)
- **J2534 Passthru support** — Works with standard off-the-shelf pass-thru adapters; no proprietary hardware required
- **Automatic checksum correction** — Safely modify bin files without manually recalculating checksums
- **Remote flashing & vendor tunes** — Securely distribute premade tunes to customers without exposing your IP

### Supported Vehicles

ECUwb supports a wide range of motorcycle and powersports ECUs across major manufacturers. Check the [supported vehicles list](https://mcuinnovations.com/vehicles/) before purchasing a license.

## Issue Tracker

This repo's [Issues](../../issues) tab is the official public bug tracker for ECU Workbench.

Before opening an issue:
- Check if it has already been reported
- Include your ECUwb version, Windows version, adapter/interface, and vehicle/ECU
- Attach a log file if applicable (Help → Open Log Folder)
